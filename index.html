Desktop Hosting Prerequisites

To host a public space from the Desktop App, your computer requires Node.js and Localtunnel to generate secure .loca.lt connection tunnels.

  1. Download and install Node.js (LTS Version recommended).
  2. Open your terminal or command prompt and install Localtunnel globally:
npm install -g localtunnel

Once installed, you can launch the Desktop App and click "Go Live & Start Hosting" to broadcast your space URL.
