# Nairobi County DES File Hub

The **Nairobi County DES File Hub** is a multi-device file-sharing and collaboration platform designed for desktops and Android devices. It enables secure space hosting, cloud resource integration, file exploration, bookmarks, offline mode, and robust moderation tools.

## 🚀 Desktop Server Hosting Requirements

To run your own shared space effectively using the Desktop app and ensure public tunneling works smoothly via `.loca.lt` links:

1. **Install Node.js:** Ensure you have [Node.js](https://nodejs.org/) installed and available on your system's PATH.
2. **Install LocalTunnel:** Install the `localtunnel` package globally on your machine so the desktop app can expose your local server publicly:
   ```bash
   npm install -g localtunnel
   ```

Once Node.js and LocalTunnel are ready, launch the Desktop app, navigate to **Shared Space Hosting**, and click **Go Live & Start Hosting**!
